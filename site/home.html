Describe a test suite in a file. Venom runs every step, checks every assertion and tells you which line failed.

Quickstart Read the docs Independent fork of ovh/venom · Apache-2.0
site/examples/quickstart.yml
name: Quickstart suite
testcases:
  - name: say hello
    steps:
      - type: exec
        script: echo "hello venom"
        assertions:
          - result.systemout ShouldContainSubstring hello
          - result.code ShouldEqual 0
